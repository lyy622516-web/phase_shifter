这是6bits移相器设计

当前腔体采用5 mm平底板、四块4 mm独立侧板和2 mm盖板，装配含PCB与左右两个SMA，共九件。SMA法兰孔为M2.2×0.45，针脚下侧至PCB顶面名义间隙0.25 mm。

四角各有两颗横向M2连接螺钉，共八颗：前角用M2×8，后角用M2×6。后角采用1 mm矩形接缝台阶，竖向框架保留六处连接位置；SMA、PCB、接口窗口及壳体外形保持原位置和尺寸。
